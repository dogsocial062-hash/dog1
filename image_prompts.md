# Image prompts for the Gemini app

How to use: open the Gemini app, attach `character_ref.png` (Kona's reference photo) to every chat, paste the prompt, and
ask for a square (1:1) image. Save it as **JPEG** named exactly as shown, then add it to the `images/` folder of the repo.
If Kona's face drifts, say: "Keep the dog's face identical to the attached photo." If text in the image is misspelled, ask again or remove the text.

Kona: young Australian Shepherd-type puppy, wide white blaze down forehead and muzzle, copper-tan cheeks and eyebrow spots, brown-and-gray merle folded ears, large round amber-brown eyes, chocolate-brown nose, fluffy fur, no collar. Always an AI-generated character.

Post days that need a real photo (owner's dog) or a collage are marked and have no prompt.
